# lucy_ros2_control

ROS 2 Control hardware plugin for Lucy-compatible robots.

**Architecture (repo-level):** [`../docs/ROS2_CONTROL.md`](../docs/ROS2_CONTROL.md) — how ros2_control maps to Lucy, SHM/Modbus, launches, and pitfalls.

## Contents

- **Hardware interface plugin** — `LucySystemHardware` in `src/lucy_system.cpp`.
- **Plugin description** — `lucy_ros2_control.xml`.

## Building

From your colcon workspace:

```bash
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select lucy_ros2_control
source install/setup.bash
```

## Hardware parameters

`LucySystemHardware` reads joint parameters from ros2_control `HardwareInfo` (the
`<param>` tags in robot-specific `*_ros2_control.xacro` generated from YAML):

- `virtual_pin`
- `offset_rad`
- `direction`
- `scale`
- `servo_min_rad`
- `servo_max_rad`
- `servo_default_rad`

Board-level params:

- `node_name` — SHM prefix (`/<node_name>.lucy_reg_table`, etc.); must match `lucy_modbus_bridge`.
- `publisher_topic` / `publish_actuators` — optional legacy `JointState` debug publisher. **Actuation uses SHM + Modbus**, not this topic.

Joints without `virtual_pin` are treated as passive/unmapped for actuator output.

## Conversion math

Internal command/state interface uses joint-space radians. SHM/Modbus registers use
**servo-space milliradians** (`rad × 1000`) at build-assigned register bases
(historically `virtual_pin * 2` for PWM cmd / `+1` for angle).

- default initialization:
  - `joint_rad = (servo_default_rad - offset_rad) * direction * scale`
- write conversion:
  - `servo_rad = actuator_command_to_servo_rad(...)` (joint → servo rad, clamped)
  - `angle_millirad = round(servo_rad * 1000)`
  - firmware maps millirad → PWM using config min/max **milliradians**

Degrees are not used in HI / firmware schemas (LCP may convert only for UI display).

## Robot-specific launch/config

This package no longer installs robot-specific launch files or controller YAML.
Those belong in robot description packages and should be generated by
`lucy_config_generator`.

## Dependencies

`controller_manager`, `hardware_interface`, `pluginlib`, `rclcpp`, `sensor_msgs`.
